# Астро Аналитик

Статический сайт для профессионального астрологического анализа: натальная карта, соляр, вторичные прогрессии, транзиты, синастрия и комплексный анализ, плюс чат с ИИ (Claude) по рассчитанным данным.

- Западная тропическая астрология, дома Плацидуса (за полярным кругом — Порфирий).
- Положения планет: [astronomy-engine](https://github.com/cosinekitty/astronomy) (точность около 1′), с аберрацией, в истинной эклиптике даты. Раху/Кету — истинные узлы, Лилит — средняя (с проекцией на эклиптику), Селена (Белая Луна) — авестийская: 242,5° на 1.01.2000, 0,1408272°/сут. Всё сверено с ZET 9 (конфигурация Avestian): планеты и куспиды Плацидуса — до секунд/минуты, узел и Селена — до нескольких секунд, Лилит — до 12″.
- Город ищется автоматически (Open-Meteo Geocoding, запасной — Nominatim): координаты, часовой пояс и смещение UTC с учётом исторического летнего времени.
- Планетарная лестница (септенер по порядку от 0° Овна), структурный анализ и сравнение космограммы (знаки) и гороскопа (дома).
- Отдельный хорарный калькулятор: сигнификаторы, совершение аспекта, рецепция, перенос света, Луна без курса, радикальность, планетарный час.
- Часовые пояса: история правил IANA через `Intl` + [tz-lookup](https://github.com/darkskyapp/tz-lookup) по координатам. Можно задать смещение UTC вручную.
- Анализ по методикам П. Глобы: дневные/ночные обители, экзальтации и падения по Глобе, ядро космограммы (стихии, кресты, зоны, квадранты, полусферы → Ян/Инь/Дэн), кармический статус планет, управители домов, планетарные возрасты.
- Конфигурации: большой трин, тау-квадрат, большой крест, йод, малый трин, «управление», стеллиумы.
- Трактовки составлены по мотивам книг П. Глобы, С. Вронского, Б. Щитова, Г. Льюи, С. Шестопалова (пересказ своими словами, без копирования текстов).

## Запуск

Сборка не нужна: это чистые HTML/CSS/JS-модули.

```
npx http-server . -p 8765
```

Откройте http://localhost:8765. Файлы нельзя открыть напрямую через `file://`, потому что модули ES требуют сервер.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Чат с ИИ

Вкладка «Чат с ИИ» использует API Claude напрямую из браузера с **вашим** ключом (console.anthropic.com → API Keys). Ключ хранится только в `localStorage` вашего браузера и отправляется только на `api.anthropic.com`. ИИ получает текстовую выжимку всех расчётов: натал, текущий соляр, прогрессии, транзиты на 12 месяцев, комплексный анализ и синастрию.

## Данные

Карты сохраняются только в браузере (`localStorage`). Поиск города идёт через OpenStreetMap Nominatim.

## Структура

- `js/astro.js` — астрономия: планеты, дома, аспекты, соляр, прогрессии, транзиты
- `js/analysis.js` — анализ по Глобе: достоинства, ядро, кармический статус, управители, конфигурации
- `js/report.js` — отчёты по всем разделам
- `js/texts/` — база трактовок
- `js/chart-svg.js` — круг карты
- `js/ai.js` — чат с Claude
